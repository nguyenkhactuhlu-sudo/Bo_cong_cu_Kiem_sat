============================================================
HƯỚNG DẪN SỬ DỤNG PdfToMdGUI
============================================================

PdfToMdGUI là công cụ chuyển đổi file PDF/Ảnh sang Markdown,
sử dụng Gemini API (Google AI) để OCR. Công cụ hỗ trợ
chuyển đổi hàng loạt, quét đệ quy thư mục con, tạo file .md
bên cạnh file gốc.

============================================================
YÊU CẦU HỆ THỐNG
============================================================
- Windows 10/11
- Microsoft Visual C++ Redistributable (nếu chạy .exe)
  * Nếu .exe báo lỗi "không tìm thấy DLL" hoặc crash,
    hãy tải VC++ Redistributable tại:
    https://aka.ms/vs/17/release/vc_redist.x64.exe
- Không cần cài Python (đã tích hợp sẵn trong file .exe)
- Kết nối Internet (để gọi Gemini API)

============================================================
CÁCH SỬ DỤNG
============================================================

A. NẾU CHẠY FILE .EXE (PdfToMdGUI.exe):
----------------------------------------------------------
1. Giải nén file PdfToMd.zip vào một thư mục bất kỳ.
2. Nhấp đúp vào PdfToMdGUI.exe để khởi chạy.
   - Lần đầu chạy có thể mất vài giây để khởi động.
   - Nếu .exe không chạy, hãy cài VC++ Redistributable
     (xem link ở phần YÊU CẦU HỆ THỐNG).
3. Trình duyệt tự động mở giao diện web.
   Nếu không mở, hãy truy cập: http://127.0.0.1:5790
   (Port có thể khác, xem thông báo trong cửa sổ console).

B. NẾU CHẠY FILE .PY (cần Python 3.8+):
----------------------------------------------------------
1. Cài Python 3.8+ từ https://python.org
2. Mở Terminal/CMD trong thư mục chứa pdf_to_md_gui.py
3. Chạy lệnh: python pdf_to_md_gui.py
4. Công cụ sẽ TỰ ĐỘNG kiểm tra và cài đặt các thư viện
   còn thiếu (flask, pypdf, aiohttp, nest-asyncio).
   Nếu không auto-install được, chạy lệnh thủ công:
   pip install flask pypdf aiohttp nest-asyncio python-docx

============================================================
CÁC BƯỚC SỬ DỤNG CHI TIẾT
============================================================

1. Bước 1 - Nhập Gemini API Key:
   - Lấy key miễn phí tại https://aistudio.google.com/apikey
   - Dán key vào ô "API Key" và bấm "Lưu API Key"
   - Key được lưu vào file API keys.txt

2. Bước 2 - Chọn thư mục:
   - Bấm "Chọn thư mục" để mở hộp thoại chọn thư mục
   - Nếu nút không hoạt động: dán đường dẫn thủ công
     vào ô nhập (VD: C:\Users\Admin\Documents\TaiLieu)
   - Bấm "Quét ngay" để xem danh sách file

3. Bước 3 - Chọn file & chuyển đổi:
   - Tích chọn file muốn chuyển đổi
   - Bấm "Thực thi chuyển đổi" để tạo file .md

============================================================
LƯU Ý QUAN TRỌNG
============================================================
- File gốc (.pdf, .jpg, .png...) được GIỮ NGUYÊN.
- File .md được tạo cùng thư mục, cùng tên với file gốc.
- PDF có text (pypdf đọc được) sẽ xử lý nhanh, miễn phí.
- PDF scan/ảnh sẽ gọi Gemini API (tốn token, chậm hơn).
- API Key được lưu trong file API keys.txt.
- Mỗi file < 20MB (giới hạn của Gemini API).

============================================================
XỬ LÝ SỰ CỐ
============================================================
- Nút "Chọn thư mục" không phản hồi:
  → Dán đường dẫn thư mục thủ công vào ô nhập và bấm
    "Quét ngay". Đây là giải pháp thay thế an toàn.

- .exe không khởi động / báo lỗi DLL:
  → Cài Microsoft Visual C++ Redistributable:
    https://aka.ms/vs/17/release/vc_redist.x64.exe

- Lỗi "Thiếu thư viện" khi chạy .py:
  → Chạy lệnh: pip install flask pypdf aiohttp nest-asyncio python-docx
    Hoặc để công cụ tự cài (cần Internet).

- Trình duyệt không tự mở:
  → Xem port trong cửa sổ console, sau đó mở trình duyệt
    và truy cập http://127.0.0.1:<port>/app
