Công cụ chuyển đổi PDF/Ảnh sang Markdown
Gemini OCR + pypdf — Hàng loạt, tự động

Giới thiệu

Công cụ PdfToMd giúp bạn chuyển đổi hàng loạt file PDF và ảnh (.pdf, .jpg, .png, .tiff, .bmp, .gif, .webp) sang định dạng Markdown (.md) một cách nhanh chóng và tự động. Công cụ quét đệ quy toàn bộ thư mục cha và các thư mục con, tạo file .md bên cạnh file gốc — giữ nguyên file gốc để bạn tiện đối chiếu.

Điểm nổi bật: OCR bằng Gemini AI — Xử lý PDF scan và ảnh — Hỗ trợ pypdf cho PDF có text (nhanh, miễn phí) — Giao diện trực quan!

Chọn thư mục cha
Tự động quét toàn bộ thư mục con, tìm file PDF/Ảnh
Xem trước danh sách
Hiển thị file theo cây thư mục, đánh dấu file đã có .md
Tích chọn linh hoạt
Chọn/bỏ chọn từng file hoặc cả thư mục để chuyển đổi
Thực thi một lần
Chuyển đổi tất cả file đã chọn, hiển thị kết quả chi tiết

Cách sử dụng

  • Bước 0: Lấy Gemini API Key miễn phí tại Google AI Studio
  • Bước 1: Tải file PdfToMd.zip về máy và giải nén
  • Bước 2: Nhấp đúp vào PdfToMdGUI.exe để chạy
  • Bước 3: Trình duyệt tự mở giao diện web. Nhập API Key, chọn thư mục cha
  • Bước 4: Bấm "Quét ngay" để xem danh sách file, tích chọn file muốn chuyển đổi
  • Bước 5: Bấm "Thực thi chuyển đổi" để tạo file .md bên cạnh file gốc

Lưu ý quan trọng: Công cụ giữ nguyên file gốc (PDF/Ảnh), chỉ tạo thêm file .md bên cạnh. PDF có text sẽ dùng pypdf (nhanh, miễn phí). PDF scan/ảnh sẽ gọi Gemini API để OCR (tốn token, có giới hạn rate limit). Mỗi file không quá 20MB.

Kết quả sau khi chuyển đổi

Sau khi chạy công cụ, mỗi file PDF/Ảnh sẽ có một file .md tương ứng nằm cùng thư mục:

📁 TaiLieuGoc/
  ├── Quyet dinh so 123.pdf    ← File gốc (giữ nguyên)
  ├── Quyet dinh so 123.md     ← File .md mới tạo ✓
  ├── Bien ban hop.jpg         ← File gốc (giữ nguyên)
  └── Bien ban hop.md         ← File .md mới tạo ✓

File .md chứa toàn bộ nội dung văn bản được OCR từ PDF/Ảnh gốc.
