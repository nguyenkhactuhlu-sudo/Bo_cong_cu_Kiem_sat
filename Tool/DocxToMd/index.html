Công cụ chuyển đổi Word sang Markdown
.doc / .docx → .md — Hàng loạt, tự động

Giới thiệu

Công cụ DocxToMd giúp bạn chuyển đổi hàng loạt file Word (.docx và .doc) sang định dạng Markdown (.md) một cách nhanh chóng và tự động. Công cụ quét đệ quy toàn bộ thư mục cha và các thư mục con, tạo file .md bên cạnh file gốc — giữ nguyên file gốc để bạn tiện đối chiếu.

Điểm nổi bật: Xử lý hàng loạt — Tự động chuyển .doc thành .docx rồi sang .md — Giữ nguyên file gốc — Giao diện trực quan!

Chọn thư mục cha
Tự động quét toàn bộ thư mục con, tìm file .doc/.docx
Xem trước danh sách
Hiển thị file theo cây thư mục, đánh dấu file đã có .md
Tích chọn linh hoạt
Chọn/bỏ chọn từng file hoặc cả thư mục để chuyển đổi
Thực thi một lần
Chuyển đổi tất cả file đã chọn, hiển thị kết quả chi tiết

Yêu cầu hệ thống

Windows 10/11
Hệ điều hành Windows (cần cho việc xử lý file .doc)
Microsoft Word
Cần cài đặt để chuyển đổi file .doc cũ (không bắt buộc với .docx)
Python 3.8+
Đã được tích hợp sẵn trong file .exe (không cần cài đặt)
Lưu ý về file .doc
File .doc định dạng cũ cần MS Word để chuyển đổi. Nếu không có Word, hãy chọn "Bỏ qua file .doc"

Cách sử dụng

  • Bước 1: Tải file DocxToMd.zip về máy và giải nén
  • Bước 2: Nhấp đúp vào DocxToMdGUI.exe để chạy
  • Bước 3: Trình duyệt tự mở giao diện web. Nhập hoặc chọn thư mục cha chứa file Word
  • Bước 4: Bấm "Quét ngay" để xem danh sách file, tích chọn file muốn chuyển đổi
  • Bước 5: Bấm "Thực thi chuyển đổi" để tạo file .md bên cạnh file gốc

Lưu ý quan trọng: Công cụ giữ nguyên file gốc (.doc/.docx), chỉ tạo thêm file .md bên cạnh. File .doc (định dạng Word cũ) sẽ được tự động chuyển thành .docx tạm thời qua Microsoft Word, sau đó trích xuất nội dung sang .md. Nếu máy bạn không cài Microsoft Word, hãy dùng tùy chọn --skip-doc hoặc tích chọn "Bỏ qua file .doc" trong giao diện GUI.

Kết quả sau khi chuyển đổi

Sau khi chạy công cụ, mỗi file Word sẽ có một file .md tương ứng nằm cùng thư mục:

📁 TaiLieuGoc/
  ├── Quyet dinh so 123.docx    ← File gốc (giữ nguyên)
  ├── Quyet dinh so 123.md     ← File .md mới tạo ✓
  ├── Bao cao tong ket.doc     ← File gốc (giữ nguyên)
  └── Bao cao tong ket.md     ← File .md mới tạo ✓

File .md chứa toàn bộ nội dung văn bản (paragraphs + tables) từ file Word gốc.
