Công cụ chuyển đổi PDF/Ảnh sang Markdown
.pdf / .jpg / .png → .md — Gemini OCR, hàng loạt, tự động

Giới thiệu

Công cụ PdfToMd giúp bạn chuyển đổi hàng loạt file PDF và ảnh (.pdf, .jpg, .png, v.v.) sang định dạng Markdown (.md) một cách nhanh chóng và tự động. Công cụ quét đệ quy toàn bộ thư mục cha và các thư mục con, tạo file .md bên cạnh file gốc — giữ nguyên file gốc để bạn tiện đối chiếu.

Điểm nổi bật: OCR bằng Gemini AI + pypdf miễn phí — Chuyển đổi hàng loạt — Giữ nguyên file gốc — Giao diện trực quan!

Định dạng file hỗ trợ

.pdf .jpg .jpeg .png .tiff .tif .bmp .gif .webp

PDF có text: Dùng pypdf — nhanh, miễn phí, không tốn token.

PDF scan / Ảnh: Dùng Gemini 2.5 Flash API — OCR chất lượng cao, tốn token.

Yêu cầu hệ thống

Windows 10/11
Hệ điều hành Windows (file .exe chạy trực tiếp, không cần cài đặt gì thêm)
Không cần Python
File .exe đã được đóng gói đầy đủ, chạy ngay không cần cài Python hay thư viện
Gemini API Key
Lấy miễn phí tại Google AI Studio
Giới hạn Gemini
File upload lên Gemini không quá 20MB. API có rate limit (khoảng 15 request/phút với key miễn phí).

Cách sử dụng

  • Bước 1: Tải file index.zip về máy và giải nén
  • Bước 2: Lấy Gemini API Key miễn phí tại Google AI Studio
  • Bước 3: Nhấp đúp vào PdfToMdGUI.exe để chạy
  • Bước 4: Trình duyệt tự mở giao diện web. Nhập API Key → Chọn thư mục → Quét → Chọn file → Chuyển đổi

Lưu ý quan trọng: Công cụ giữ nguyên file gốc (.pdf, .jpg, .png...), chỉ tạo thêm file .md bên cạnh. API Key của bạn được lưu trong bộ nhớ trình duyệt (localStorage), không gửi đi đâu khác ngoài Gemini API của chính Google. PDF có text sẽ được xử lý bằng pypdf (nhanh, miễn phí), chỉ PDF scan và ảnh mới gọi Gemini API.

Kết quả sau khi chuyển đổi

Thông tin phát triển

Engine: Gemini 2.5 Flash API + pypdf — OCR PDF/Ảnh sang Markdown

An toàn: Giữ nguyên file gốc — Chỉ tạo thêm file .md, không sửa/xóa file gốc

Công nghệ: Flask + HTML/CSS/JS — Giao diện web trực quan, chạy local

Hỗ trợ: .pdf, .jpg, .jpeg, .png, .tiff, .tif, .bmp, .gif, .webp

Concurrent: 1-5 workers đồng thời với asyncio + aiohttp

Anti-hallucination: Fuzzy check chống ảo giác, tự động reject kết quả sai
